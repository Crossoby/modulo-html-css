Bitácora de accesibilidad web


1. Hallazgos de accesibilidad y correcciones

| Página | Hallazgo | Corrección |
|---|---|---|
| Inicio | Las imágenes tienen textos alternativos poco descriptivos, como alt="logo" y alt="Imagen Bicicleta". | Utilizar descripciones más claras, como alt="Logo de Rueda Libre" y alt="Bicicleta disponible para alquiler". |
| Reservas y Tarifas | El idioma está declarado como lang="en", aunque el contenido está en español. | Cambiarlo por lang="es". |
| Las tres páginas | Los encabezados h2 están ubicados directamente dentro de listas ul. | Colocar los encabezados fuera de las listas. |
| Inicio | El enlace «Consultar» no describe claramente su destino. | Cambiarlo por «Consultar tarifas de alquiler». |
| Inicio | El enlace hacia los recorridos apunta a #Tabla, pero la sección de destino tiene id="tabla". | Utilizar href="paginas/tarifas.html#tabla". |
| Inicio | El encabezado «Nuestra ubicación» utiliza h4 sin un h3 anterior. | Cambiarlo por h3. |
| Reservas | La etiqueta de comentarios no coincide con el identificador del campo de texto. | Utilizar for="comentarios" e id="comentarios", con una etiqueta descriptiva. |
| Tarifas | No existe un encabezado principal h1. | Agregar `<h1>Tarifas de Rueda Libre</h1>. |
